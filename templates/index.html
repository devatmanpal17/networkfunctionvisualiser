FIELD GUIDE

Your first five minutes.

Arc is an educational model of Network Function Virtualization (NFV): software services that perform jobs traditionally done by dedicated network appliances.

  1. Pin a baseline. Save the current metrics so every experiment has a comparison.
  2. Launch a mission. Try a demand surge, replica failure, or attack.
  3. Follow the response. Inspect the chain, telemetry chart, and decisions. The model advances every two seconds.
  4. Change the policy. Compare latency and cost, or disable autoscaling and adjust replicas yourself.
  5. Keep your findings. Export the JSON report or CSV telemetry for your project write-up.
VNF
A virtual network function, such as the firewall or load balancer.
SDN
Software-defined networking separates forwarding from control decisions.
MANO
Management and orchestration: the logic that adds or removes capacity.
NFVI
The compute, memory, and network resources shared by the VNFs.
SLA
A performance target. This lab uses latency <20 ms, packet loss <1%, and modeled availability ≥99%.

Telemetry, threat counts, cost, availability, regions, and packets are synthetic. Arc does not run Ryu, Open vSwitch, Docker, TLS decryption, or real attacks. Sessions live in server memory and reset on restart.
